## Aliases

Common shorthand may be resolved as follows:

```text
retro editorial     → retro-naive-editorial
playful editorial   → playful-naive-editorial
tension lines       → conceptual-tension-linework
place linework      → place-narrative-linework
storybook print     → storybook-printmaking
paper cover         → poetic-paper-cover
field notes         → observational-field-notes
pastel geometry     → pastel-impossible-geometry
archival halftone   → archival-halftone-minimalism
```

If no preset is named, select the closest preset from the user's visual description.
